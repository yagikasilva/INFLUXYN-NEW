# INFLUXYN — Polished Website

This package keeps the existing INFLUXYN content, pages, social links, animations and JavaScript functions while applying a polished visual refinement.

## Preserved
- Responsive navigation and mobile menu
- Light/dark theme toggle
- Scroll progress bar
- Scroll reveal animations
- Hero typing animation
- Pricing LKR/USD switch
- Project/category filtering
- Contact-to-WhatsApp form flow
- WhatsApp floating CTA
- All existing service/project/blog/demo links
- Facebook, LinkedIn, Instagram and TikTok links
- SEO metadata, schema, sitemap and robots files

## Visual improvements
- Cleaner spacing and hierarchy
- More refined card hover states
- Polished header and mobile navigation
- Subtle hero/terminal motion
- Better CTA and button interactions
- Improved form focus states
- Refined FAQ interactions
- Social link pill styling
- Better responsive behavior
- Reduced-motion support remains enabled

Deploy the contents of this folder to the website root.
